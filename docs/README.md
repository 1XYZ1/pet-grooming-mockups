# Prototipo Auth – Pet Grooming App 🐾🔐

Mock-up interactivo del **módulo de autenticación** para la aplicación de gestión de peluquería canina *Pet Grooming*.  
Diseñado por **Ramón Hernández** y **Tomás Riquelme** siguiendo buenas prácticas de control de versiones y con enfoque en calidad de software (seguridad, usabilidad, trazabilidad).

---

## ✨ Objetivos

| Rol | Flujo principal | Requisitos clave |
|-----|-----------------|------------------|
| **Administrador** | Inicia sesión → Dashboard | - Valida credenciales  <br>- Bloqueo tras 3 intentos |
| **Peluquero** | Login → Panel propio | - Acceso por correo/contraseña |
| **Cliente** | Registro → Confirmación e-mail → Login | - Captcha  <br>- Enlace de confirmación  <br>- Recuperación de contraseña (link temporal) |

> Todas las pantallas fueron iteradas en Mockitt y versionadas con **Git + Git LFS** para conservar el historial visual.
